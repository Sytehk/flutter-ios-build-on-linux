# Stock Flutter counter app

This is the default Flutter 3.50.0 counter app generated for iOS with `flutter create --platforms=ios --org com.example.sweetpad --project-name stock_flutter`.

Follow the [stock app walkthrough](../../README.md#stock-app-walkthrough) to copy the example out of the tools checkout, set a bundle ID, and build, sign, and run it on an iPhone from Linux.
